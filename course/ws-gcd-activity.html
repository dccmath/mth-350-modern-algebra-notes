    Worksheet Module 4: Greatest Common Divisors, the Euclidean Algorithm, and Linear Combinations
    

    Numbers
    🔗

    Greatest Common Divisors.

    Here’s the formal definition of greatest common divisor:
    🔗

    Definition 17.

    Let \(a\) and \(b\) be integers, not both zero. A common divisor of \(a\) and \(b\) is any integer \(k\) such that \(k\mid a\) and \(k\mid b\text{.}\) We say that an integer \(d\) is the greatest common divisor of \(a\) and \(b\text{,}\) denoted \(\gcd(a,b)\text{,}\) provided that \(d\) is a common divisor of \(a\) and \(b\text{,}\) and if \(k\) is a common divisor of \(a\) and \(b\) then \(k\leq d\text{.}\)
    🔗
    🔗
    🔗

    Applying The Euclidean Algorithm.

    Find \(\gcd(27182, 3141)\) using the Euclidean algorithm. If you’d like another example see page 26 of your text.
    🔗
    🔗

    Why The Euclidean Algorithm Works.

    Here’s a theorem that explains why the Euclidean algorithm works:
    🔗

    Theorem 18.

    Let \(a\) and \(b\) be integers, not both \(0\) and suppose that
    \begin{equation*} b = aq + r \end{equation*}
    for some integers \(q\) and \(r\text{.}\) Then \(\gcd(b,a) = \gcd(a,r)\text{.}\)
    🔗
    🔗

    1.

    Assuming the hypothesis of the theorem, prove that if \(d\) is a common divisor of \(a\) and \(b\) then \(d\) is a common divisor of \(a\) and \(r\text{.}\)
    🔗
    🔗

    2.

    Assuming the hypothesis of the theorem, prove that if \(d\) is a common divisor of \(a\) and \(r\) then \(d\) is a common divisor of \(a\) and \(b\text{.}\)
    🔗
    🔗

    3.

    How do the previous 2 parts show that \(\gcd(a,r) = \gcd(a,b)\text{?}\)
    🔗
    🔗

    4.

    How is this theorem related to the Euclidean algorithm?
    🔗
    🔗
    🔗

    Linear Combinations and Back Substitution.

    Definition 19.

    Let \(a\) and \(b\) be integers. A linear combination of \(a\) and \(b\) is an integer that can be written as \(ax+by\) for some integers \(x\) and \(y\text{.}\)
    🔗
    🔗
    Recall that we found \(\gcd(540,765) = 45\) using the Euclidean algorithm as follows:
    🔗
    \begin{align} 765&= 540\cdot 1 + 225\tag{1}\\ 540&= 225 \cdot 2 + 90\tag{2}\\ 225&= 90 \cdot 2 + 45\tag{3}\\ 90&= 45 \cdot 2 + 0.\tag{4} \end{align}
    Using these equations, we will find integers \(x\) and \(y\) such that \(765 x + 540 y = 45\text{.}\)
    🔗

    5.

    Note from equation (3) we have
    \begin{equation*} 45 = 225+90\cdot (-2). \end{equation*}
    Solve for \(90\) in equation (2) and substitute into this equation. Do not simplify.
    🔗
    🔗

    6.

    Rewrite the equation you found in (a) so that you have 45 as a linear combination of \(225\) and \(540\text{.}\)
    🔗
    🔗

    7.

    Now, using equation (1), substitute for \(225\) in the equation you have for part (b). Rewrite so that you have \(45\) as a linear combination of \(765\) and \(540\text{.}\)
    🔗
    🔗
    🔗

    8.

    Using the Euclidean algorithm you can always find \(\gcd(a,b)\text{.}\) Then using this “back-substitution” method with the Euclidean algorithm you can always write the greatest common divisor of \(a\) and \(b\) as a linear combination of \(a\) and \(b\text{.}\) Together some call this the “Extended Euclidean Algorithm”. Using the Euclidean Algorithm find \(\gcd(816, 188)\) and find \(x\) and \(y\) such that \(\gcd(816,188) = 816x + 188y\text{.}\)
    🔗
    🔗

    9.

    If time: Are these linear combinations unique? E.g., can you find more than one linear combination of \(3\) and \(5\) that equals \(1\text{?}\)
    🔗
    🔗

    10.

    If time: Use your work finding \(\gcd(27182,3141)\) to write \(1\) as a linear combination of \(27182\) and \(3141\text{.}\)
    🔗
    🔗

    Bezout’s Identity.

    Here are two important theorems in number theory:
    🔗

    Theorem 20. Bezout’s Identity.

    Let \(a\) and \(b\) be integers, not both zero. Then \(\gcd(a,b)\) can be written as a linear combination of \(a\) and \(b\text{.}\) That is, there exist integers \(x\) and \(y\) such that
    \begin{equation*} \gcd(a,b) = ax + by. \end{equation*}
    🔗
    🔗
    This is at first surprising! There is no reason there should be integers \(x\) and \(y\) such that \(12345x+54321y = 3\text{.}\) But based on the work on the previous page, you can always back-substitute from the Euclidean algorithm.
    🔗

    Corollary 21.

    Let \(a\) and \(b\) be integers, not both zero. Then \(\gcd(a,b)\) is equal to the smallest positive linear combination of \(a\) and \(b\text{.}\)
    🔗
    🔗
    The fact that it is the smallest positive linear combination is a Weekly Practice Problem - \(\gcd(a,b)\) divides every linear combination of \(a\) and \(b\text{.}\)
    🔗
    We will skip proofs of these theorems and opt to see applications of these theorems instead.
    🔗

    11.

    Suppose \(a=3\) and \(b=2\text{.}\) Then, letting \(x = 1\) and \(y=1\) we find \(ax+by=5\text{.}\) Does it follow from Bezout’s Identity that \(\gcd(3,2)=5\text{?}\)
    🔗
    🔗

    12.

    Let \(a\) and \(b\) be integers. Suppose there exist integers \(x\) and \(y\) such that \(ax+by=k\text{.}\) Does it follow that \(\gcd(a,b)=k\text{?}\) If so, explain. If not, what can you say about \(\gcd(a,b)\text{?}\) Hint: Show \(\gcd(a,b)\) divides any linear combination of \(a\) and \(b\text{.}\)
    🔗
    🔗

    13.

    Let \(a\) and \(b\) be integers. Suppose there exist integers \(x\) and \(y\) such that \(ax+by=1\text{.}\) Does it follow that \(\gcd(a,b)=1\text{?}\) If so, explain. If not, what can you say about \(\gcd(a,b)\text{?}\) Note: For two integers \(a\) and \(b\text{,}\) not both \(0\text{,}\) we say \(a\) and \(b\) are relatively prime provided that \(\gcd(a,b) = 1\text{.}\)
    🔗
    🔗
    🔗

    Fun With Linear Combinations.

    14.

    Let’s see a connection between Multiplicative Inverses and GCD’s:
    🔗

    (a)

    In \(\mathbb{Z}_{10}\text{,}\) find \(([7]_{10})^{-1}\text{.}\) That is, find the multiplicative inverse of \([7]\) in \(\mathbb{Z}_{10}\text{.}\)
    🔗
    🔗

    (b)

    Find a linear combination of \(7\) and \(10\) that is equal to \(\gcd(7,10)\text{.}\) (If you don’t see it right away, use the Euclidean Algorithm and back substitution, it’s good practice!) How is your answer related to the multiplicative inverse of \([7]\) in \(\mathbb{Z}_{10}\text{?}\)
    🔗
    🔗

    (c)

    Does \([2]_{10}\) have a multiplicative inverse in \(\mathbb{Z}_{10}\text{?}\) How does this relate to greatest common divisors and linear combinations?
    🔗
    🔗
    🔗

    Weekly Practice 4.

    1.

    (This is good practice for Learning Target 6.) For each of the following values of \(a\) and \(b\text{,}\) use the Euclidean algorithm to determine \(\gcd(a,b)\text{.}\) Then find integers \(x\) and \(y\) such that \(ax+by = \gcd(a,b)\text{.}\)
    🔗

    (a)

    \(a= 525\text{,}\) \(b=252\)
    🔗
    🔗

    (b)

    \(a=54321\text{,}\) \(b=12345\)
    🔗
    🔗

    (c)

    \(a=27182\text{,}\) \(b=-3141\text{.}\) (Note we did \(\gcd(27182,3141)\) in class!)
    🔗
    🔗
    🔗

    2.

    (This is good practice for Learning Target 7.) Decide whether each of the following statements is true or false. For those that are true, explain why. For those that are false, give a counterexample and then change one word or symbol in the statement to make it true. For each statement, assume that \(a,b,\) and \(d\) are positive integers.
    🔗

    (a)

    If \(ax+by = 1\) for some integers \(x\) and \(y\text{,}\) then \(\gcd(a,b)=1\text{.}\)
    🔗
    🔗

    (b)

    If \(ax+by \neq 1\) for some integers \(x\) and \(y\text{,}\) then \(\gcd(a,b)\neq 1\text{.}\)
    🔗
    🔗

    (c)

    If \(x+by=d\) for some integers \(x\) and \(y\text{,}\) then \(\gcd(a,b) = d\text{.}\)
    🔗
    🔗
    🔗

    3.

    Prove that \(\gcd(a,b)\) divides every linear combination of \(a\) and \(b\text{.}\) That is, prove that for all \(x,y\in\mathbb{Z}\text{,}\) \(\gcd(a,b) \mid ax+by\text{.}\) Explain why this proves the Corollary to Bezout’s Identity given in this packet.
