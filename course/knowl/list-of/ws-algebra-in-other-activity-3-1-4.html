Definition 36 The number system \(\mathcal{P}_{n}\).

For any natural number \(n\text{,}\) the number system \(\mathcal{P}_{n}\) is \((\mathcal{P}(\{1,2,\dots, n\}), \triangle, \cap)\text{.}\) That is, the elements are the sets that are subsets of \(\{1,2,\dots, n\}\text{,}\) and for \(A,B\in \mathcal{P}_{n}\) we define \(A+B = A\triangle B\) and \(A\cdot B = A \cap B\text{.}\)
