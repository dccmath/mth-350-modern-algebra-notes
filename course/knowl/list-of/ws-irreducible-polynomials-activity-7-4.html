Theorem 65 Eisenstein’s Criterion.

Let \(f(x) = a_{n}x^{n} +a_{n-1}x^{n-1}+ \cdots + a_{1}x + a_{0}\in \mathbb{Z}[x]\) have degree \(n>1\text{.}\) If there is a prime \(p\) so that \(p\mid a_{i}\) for \(1\le i \le n-1\text{,}\) but \(p\nmid a_{n}\text{,}\) and \(p^{2}\nmid a_{0}\text{,}\) then \(f(x)\) is irreducible in \(\mathbb{Q}[x]\text{.}\)
