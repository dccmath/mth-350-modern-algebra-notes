Definition 10 Equivalence relation.

Let \(S\) be a set and let \(\sim\) be a binary relation on \(S\text{.}\) Then \(\sim\) is called an equivalence relation on \(S\) provided that \(\sim\) satisfies all of the following properties:
  1. Reflexive: For all \(a \in S\text{,}\) \(a \sim a\text{.}\)
    🔗
    🔗
  2. Symmetric: For all \(a, b \in S\text{,}\) if \(a \sim b\) then \(b \sim a\text{.}\)
    🔗
    🔗
  3. Transitive: For all \(a, b, c \in S\text{,}\) if \(a \sim b\) and \(b \sim c\) then \(a \sim c\text{.}\)
