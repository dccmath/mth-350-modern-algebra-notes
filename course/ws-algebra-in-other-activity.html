    Power Sets.

    Definition 34 Power set.

    Let \(S\) be a set. The power set of \(S\) denoted \(\mathcal{P}(S)\) is the collection of all subsets of \(S\text{.}\) That is \(\mathcal{P}(S)=\{T: T\subseteq S\}\text{.}\)
    🔗
    🔗

    Definition 35 Symmetric difference.

    For any sets \(A\) and \(B\text{,}\) the symmetric difference of \(A\) and \(B\text{,}\) denoted \(A \triangle B\) is the set of all elements that belong to either \(A\) or \(B\text{,}\) but not both. That is,
    \begin{equation*} A \triangle B = \{x: x\in A\cup B \text{ and }x\not\in A\cap B\}. \end{equation*}
    🔗
    🔗

    Definition 36 The number system \(\mathcal{P}_{n}\).

    For any natural number \(n\text{,}\) the number system \(\mathcal{P}_{n}\) is \((\mathcal{P}(\{1,2,\dots, n\}), \triangle, \cap)\text{.}\) That is, the elements are the sets that are subsets of \(\{1,2,\dots, n\}\text{,}\) and for \(A,B\in \mathcal{P}_{n}\) we define \(A+B = A\triangle B\) and \(A\cdot B = A \cap B\text{.}\)
    🔗
    🔗
    🔗

    Polynomials.

    Definition 37 Polynomial in \(x\) over \(R\).

    Let \(R\) be a commutative ring. A polynomial in \(x\) over \(R\) is an expression of the form
    \begin{equation*} a_{n}x^{n} + a_{n-1}x^{n-1}+ \cdots a_{2}x^{2} + a_{1}x^{1} + a_{0}x^{0}, \end{equation*}
    where \(n\) is a nonnegative integer and \(a_{n},a_{n-1},\dots,a_{2},a_{1},a_{0}\) are elements of \(R\text{.}\) The polynomial ring over \(R\) is the set of all polynomials over the ring \(R\text{,}\) and is denoted \(R[x]\text{.}\) (Note this language implies the polynomials form a ring. We’ll take this as true, and just verify a couple of properties. The proof is mostly tedious and not insightful.
    🔗
    🔗

    Definition 38 Adding polynomials.

    Adding Polynomials: The sum of polynomials \(p(x)\) and \(q(x)\) is defined to be
    \begin{equation*} p(x) + q(x) = (a_{n}+b_{n})x^{n} + (a_{n-1}+b_{n-1})x^{n-1}+ \cdots + (a_{1}+b_{1}) x + (a_{0}+b_{0}). \end{equation*}
    🔗
    🔗

    Definition 39 Multiplying polynomials.

    Multiplying Polynomials: The product of polynomials \(p(x)\) (of degree \(m\)) and \(q(x)\) (of degree \(n\)) is defined to be
    \begin{equation*} p(x)q(x) = c_{m+n}x^{m+n}+ c_{m+n-1}x^{m+n-1}+ \cdots + c_{2}x^{2} + c_{1}x + c_{0}. \end{equation*}
    where for each \(k\) with \(0\le k \le m+n\text{,}\)
    \begin{equation*} c_{k} = a_{k}b_{0} + a_{k-1}b_{1} + a_{k-2}b_{2} + \cdots + a_{2}b_{k-2}+ a_{1}b_{k-1}+a_{0}b_{k}. \end{equation*}
    🔗

    1. Positive reals.

    Let \(\mathbb{R}^{+}\) denote the set of all positive real numbers. (Note \(0\) is not positive!) For all \(x,y\in \mathbb{R}^{+}\) define
    \begin{equation*} x\oplus y = xy \text{ and }x\otimes y = x^{\log(y)}. \end{equation*}
    🔗

    (a)

    With these properties, does \(\mathbb{R}^{+}\) have an additive identity? If so, what is it?

    2. Complex numbers.

    A complex number is any number of the form \(a+bi\) where \(a,b\in \mathbb{R}\) and \(i\) is an imaginary number with the property that \(i^{2} = -1\text{.}\) For a complex number \(x=a+bi\text{,}\) the real number is called the real part of \(x\) and \(b\) is called the imaginary part of \(x\text{.}\) So
    \begin{equation*} \mathbb{C}= \{a+bi: a\in \mathbb{R}, b\in\mathbb{R}, \text{ and }i^{2} = -1\}. \end{equation*}
    Furthermore, addition and multiplication within \(\mathbb{C}\) are defined by
    \begin{equation*} (a+bi) + (c+di) = (a+c) + (b+d)i \end{equation*}
    and
    \begin{equation*} (a+bi)(c+di) = (ac - bd) + (ad+bc)i. \end{equation*}
    The complex numbers turn out to be a field. Let’s show every nonzero element has a multiplicative inverse. That is, we want to show, for \(x=a+bi\) where \(a\) and \(b\) are not both \(0\text{,}\) there exists \(y=c+di\) such that
    \begin{equation*} 1 + 0i = xy = (a+bi)\cdot (c+di) = (ac-bd) +(ad+bc)i. \end{equation*}
    🔗
    So we want \(ac-bd = 1\) and \(ad+bc = 0\text{.}\)
    🔗

    (a)

    Solve the system of equations
    🔗
    \begin{align*} ac-bd&= 1\\ ad+bc&= 0 \end{align*}
    for \(c\) and \(d\text{,}\) getting expressions that only depend on \(a\) and \(b\text{.}\) (You can do so using substitution. One way is to solve for \(d\) in the second equation, plug your answer into the first equation, and then solve for \(c\text{.}\) Then use what you know for \(c\) to find \(d\text{.}\))
    🔗
    🔗

    (b)

    Verify that your answer in (a) gives the multiplicative inverse for \(a+bi\text{.}\) That is, \((a+bi)(c+di) = 1 + 0i\text{.}\)
    🔗
    🔗
    🔗
