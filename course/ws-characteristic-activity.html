    The Characteristic of a Ring.

    The characteristic of a ring allows us to make some interesting observations, like “the Freshman’s dream.”
    🔗
    Before we define characteristic, let’s consider some questions.
    🔗

    5.

    For which positive integers \(k\) does \(k[3] = [0]\) in \(\mathbb{Z}_{12}\text{?}\)
    🔗
    🔗

    6.

    For which positive integers \(k\) does \(k[4] = [0]\) in \(\mathbb{Z}_{12}\text{?}\)
    🔗
    🔗

    7.

    For which positive integers \(k\) does \(k[5] = [0]\) in \(\mathbb{Z}_{12}\text{?}\)
    🔗
    🔗

    8.

    Are there positive integers \(k\) such that \(k[x] = [0]\) in \(\mathbb{Z}_{12}\) for all \([x]\in\mathbb{Z}_{12}\text{?}\)
    🔗
    🔗

    9.

    Are there positive integers \(k\) such that \(kx = 0\) for all \(x\in \mathbb{Z}\text{?}\)
    🔗
    🔗

    Definition 68.

    Let \(R\) be a ring. The characteristic of \(R\text{,}\) denoted \(char(R)\) is the smallest positive integer \(k\) such that
    \begin{equation*} kx = 0_{R} \text{ for all $x\in R$}. \end{equation*}
    If no such integer exists, then \(R\) is said to be characteristic zero.
    🔗
    🔗
    🔗

    10.

    A classmate of yours claims that \(char(\mathcal{P}_{n}) = 2\) and offers the following argument:
    🔗
    Let \(S\in\mathcal{P}_{n}\text{.}\) Then
    \begin{equation*} 2S = S + S = S\Delta S = \emptyset = 0_{\mathcal{P}_n}. \end{equation*}
    Thus, \(char(\mathcal{P}_{n}) = 2\text{.}\)
    🔗
    Is the classmate’s claim correct? Is their argument correct?
    🔗
    🔗

    Theorem 69.

    For every integer \(n\ge 2\text{,}\) \(char(\mathbb{Z}_{n}) = n\text{.}\)
    🔗
    🔗

    Proof.
    Let \(n\ge 2\text{.}\) Note that \(n\) is a positive integer, so it is a possible characteristic of a ring. Note that for all \([x]\in\mathbb{Z}_{n}\text{,}\)
    \begin{equation*} n[x] = [nx] = [n][x] = [0][x] = [0]. \end{equation*}
    Let \(k\) be any positive integer with \(k<n\text{.}\) It follows that \(n\nmid k\) and so
    \begin{equation*} k[1] = [k] \neq [0]. \end{equation*}
    Therefore \(char(\mathbb{Z}_{n}) = n\text{.}\)
    🔗
    🔗

    Fun facts.

    • In general, it is not true that \((x+y)^{2} = x^{2}+y^{2}\text{.}\) We’d say a high school freshman is “dreaming” if they think that’s true. It is however true, for \(x,y \in \mathbb{Z}_{2}\text{,}\) and for any ring of characteristic \(p\) where \(p\) is a prime,
      \begin{equation*} (x+y)^{p} = x^{p} + y^{p}. \end{equation*}
      You can actually use the “Freshman’s Dream” to test if a large number is prime!
      🔗
      🔗
    • The characteristic of a field is always \(0\) or a \(p\) for a prime \(p\text{.}\)
      🔗
      🔗
    • If \(R\) and \(S\) are rings and there exists a ring homomorphism \(\phi: R \to S\text{,}\) then the characteristic of \(S\) divides the characteristic of \(R\text{.}\)
      🔗
