    A Strange New World

    Equivalence Relations.

    Definition 41.

    Let \(S\) be a set and let \(\sim\) be a binary relation on \(S\text{.}\) Then \(\sim\) is called an equivalence relation on \(S\) provided that \(\sim\) satisfies all of the following properties:
    1. Reflexive: For all \(a \in S\text{,}\) \(a \sim a\text{.}\)
      🔗
      🔗
    2. Symmetric: For all \(a, b \in S\text{,}\) if \(a \sim b\) then \(b \sim a\text{.}\)
      🔗
      🔗
    3. Transitive: For all \(a, b, c \in S\text{,}\) if \(a \sim b\) and \(b \sim c\) then \(a \sim c\text{.}\)
      🔗
      🔗
    🔗
    🔗

    1.

    Which of the properties of reflexive, symmetric, and transitive are satisfied by each of the following relations on the given set \(S\text{?}\) Sketch a proof or a counterexample to justify each of your answers.
    🔗

    (a)

    Number of digits relation: Let \(S = \{1,2,3, \dots, 999, 1000\}\) and consider the relation \(\sim\) defined by \(a\sim b\) if and only if \(a\) has the same number of digits as \(b\text{.}\)
    🔗
    🔗

    (b)

    Divides relation: Let \(S = \mathbb{N}\) and consider the relation \(\sim\) defined by \(a\sim b\) if and only if \(a\mid b\text{.}\)
    🔗
    🔗

    (c)

    Sum to 10 relation: Let \(S = \mathbb{N}\) and consider the relation \(\sim\) defined by \(a \sim b\) if and only if \(a+b = 10\text{.}\)
    🔗
    🔗

    (d)

    Rhyming relation: Let \(S\) be the set of all words in the English language and for words \(a\) and \(b\) say \(a\sim b\) if and only if \(a\) rhymes with \(b\text{.}\)
    🔗
    🔗

    (e)

    Fraction relation: Let \(S = \mathbb{Q}\) and for \(a,b\in \mathbb{Q}\) define \(a\sim b\) if and only if \(a-b\in \mathbb{Z}\text{.}\)
    🔗
    🔗

    Equivalence Classes.

    Definition 44.

    Let \(\sim\) be an equivalence relation on a nonempty set \(S\text{,}\) and let \(a\in S\text{.}\) The equivalence class of \(a\) (with respect to \(\sim\) ) denoted \([a]_{\sim}\) is the set of all elements of \(S\) that are related to \(a\) by \(\sim\text{.}\) More precisely,
    \begin{equation*} [a]_{\sim}= \{ x \in S: x\sim a\}. \end{equation*}
    🔗
    🔗

    Some Properties of Equivalence Classes.

    The reason we define an equivalence relation to have the properties reflexive, symmetric, and transitive is that it leads to equivalence classes that have some special properties.
    🔗

    3.

    We’ll start by considering the following lemma.

    Lemma 47.

    Let \(S\) be a nonempty set and let \(\sim\) be an equivalence relation on \(S\text{.}\) Then for all \(a,b\in S\text{,}\) \([a]=[b]\) if and only if \(a\sim b\text{.}\)
    🔗
    🔗
    🔗

    (a)

    Let’s see what this lemma means about congruence classes, that is, equivalence classes under the equivalence relation congruence modulo \(n\text{.}\) Give an example of \(a, b \in \mathbb{Z}\) for which congruence classes modulo \(5\) are equal. Is \(a\sim b\) where \(\sim\) is congruence modulo \(5\text{?}\) Then give an example for which \(a\sim b\text{,}\) and determine if \([a]_{5} = [b]_{5}\text{.}\)
    🔗
    🔗

    (b)

    This Lemma means for a given equivalence class there are many different ways to write it, we call this “picking a representative”. Which representatives might make sense to use for the congruence classes modulo \(8\text{?}\)
    🔗
    🔗
    🔗

    4.

    Now let’s consider the following theorem.

    Theorem 49.

    Let \(S\) be a nonempty set and let \(\sim\) be an equivalence relation on \(S\text{.}\) Then \(S\) can be written as the disjoint union of distinct equivalence classes corresponding to \(\sim\text{.}\) That is,
    1. For all \(a,b\in S\text{,}\) if \([a] \neq [b]\) then \([a] \cap [b] = \emptyset\text{.}\)
      🔗
      🔗
    2. For all \(a\in S\text{,}\) \(a\in [a]\text{.}\)
      🔗
      🔗
    3. For all \(a\in S\text{,}\) if \(a\in [b]\) for some \(b \in S\text{,}\) then \([a] = [b]\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    The Number System \(\Z_{n}\).

    For our purposes, the most important equivalence relation will be congruence modulo \(n\text{.}\) This allows us to define the number system \(\mathbb{Z}_{n}\text{:}\)
    🔗

    Definition 50.

    For every integer \(n\ge 2\text{,}\) the integers modulo \(n\) denoted \(\mathbb{Z}_{n}\text{,}\) is the set of the distinct congruence classes of \(\Z\) modulo \(n\text{,}\) i.e.,
    \begin{equation*} \Z_{n} = \{[0]_{n}, [1]_{n}, [2]_{n}, \dots, [n-1]_{n}\}. \end{equation*}
    🔗
    🔗
    We can make \(\Z_{n}\) into a number system by defining addition and multiplication on the set:
    • Addition: \([a]_{n} + [b]_{n}= [a+b]_{n}\)
      🔗
      🔗
    • Multiplication: \([a]_{n}\cdot [b]_{n} = [a\cdot b]_{n}\)
      🔗
      🔗
    This may seem like a silly thing to do, but remember that \([a]_{n}\) is actually an infinite set! In fact, the two \(+\)’s actually, in a sense, have a different meaning. The one on the left is saying “add these infinite sets” and the one on the right is saying “add these two integers”.
    🔗

    Example 51.

    Let’s consider \(\Z_{4} = \{ [0]_{4}, [1]_{4}, [2]_{4}, [3]_{4}\}\) . We’ll find \([3]_{4} + [2]_{4}\) . We are really finding:
    \begin{equation*} [3]_{4} + [2]_{4} = \{ \dots, -1, 3, 7, \dots\} + \{ \dots, -2, 2, 6, \dots\} \end{equation*}
    which is kind of a crazy thing to think about. Using the definition of addition above this is
    \begin{equation*} [3]_{4} + [2]_{4} = [3+2]_{4} = [5]_{4} . \end{equation*}
    But \([5]_{4}\) appears to not be in \(\Z_{4}\) . Is \(\Z_{n}\) not closed? Turns out that it’s OK: Recall that \([5]_{4} = [1]_{4}\) . They are the same sets! So we’ll say
    \begin{equation*} [3]_{4} + [2]_{4} = [3+2]_{4} = [5]_{4} = [1]_{4} . \end{equation*}
    In our addition and multiplication tables, we’ll write this “reduced” answer. That is, if we get a congruence class that appears to not be in the set, we will choose a “representative” that is between \(0\) and \(n-1\) .
    🔗
    🔗

    3. Multiplicative cancellation.

    One of the things our high school teachers told us about is “multiplicative cancellation” (although they probably didn’t use those words). As an example, if we have \(6x = 5x^2\) we could “cancel” the \(x\)’s so that we have \(6 = 5x\text{.}\) But in high school we were almost always working in \(\mathbb{R}\text{.}\) This question asks about multiplicative cancellation in \(\mathbb{Z}_n\text{.}\)
    🔗

    (a)

    The statement at the start isn’t quite precise enough. There’s one \(x\) value for which multiplicative cancellation doesn’t work. What is it, and why doesn’t it work?
    🔗
    🔗

    (b)

    Consider \(n = 12\text{.}\) For \([a],[b],[c]\in\mathbb{Z}_{12}\) with \([c] \neq [0]\text{,}\) if \([a][c] = [b][c]\) does \([a]=[b]\text{?}\) (Hint: Look at your multiplication table for \(\mathbb{Z}_{12}\text{!}\))
    🔗
    🔗

    (c)

    Consider \(n = 11\text{.}\) For \([a],[b],[c]\in\mathbb{Z}_{11}\) with \([c] \neq [0]\text{,}\) if \([a][c] = [b][c]\) does \([a]=[b]\text{?}\)
    🔗
