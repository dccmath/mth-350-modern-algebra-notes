    The Good Place
    🔗

    Sets of Numbers (and one set of matrices).

    We’ll start with some formalizing of things you have likely seen before:
    1. The set of natural numbers is \(\mathbb{N}= \{1,2,3,\dots\}.\)
      🔗
      🔗
    2. The set of whole numbers is \(\mathbb{W}= \{0,1,2,3,\dots\}.\)
      🔗
      🔗
    3. The set of integers is all positive and negative natural numbers, as well as 0:
      \begin{equation*} \mathbb{Z}= \{\dots,-3,-2,-1,0,1,2,3,\dots\}. \end{equation*}
      🔗
      🔗
    4. The set of rational numbers is \(\mathbb{Q}= \left\{\frac{a}{b}: a,b \in \mathbb{Z}, b\neq 0\right\}.\)
      🔗
      🔗
    5. The set of real numbers, denoted \(\mathbb{R}\) is something you likely have an intuitive idea about. Defining \(\mathbb{R}\) rigorously is actually quite difficult, and can occupy a significant amount of time in a first course in real analysis. So we’ll make use of your intuition in this class.
      🔗
      🔗
    6. The set of irrational numbers is \(\mathbb{R}\setminus \mathbb{Q}\text{.}\) That is, the set of real numbers that are not rational.
      🔗
      🔗
    7. The set of complex numbers is \(\mathbb{C}= \{a+bi: a,b\in\mathbb{R}\}.\)
      🔗
      🔗
    8. The set of \(2\times 2\) matrices with real entries is
      \begin{equation*} \mathcal{M}_{2}(\mathbb{R}) = \left\{ \begin{bmatrix}a &b \\ c &d\end{bmatrix}: a,b,c,d\in\mathbb{R}\right\}. \end{equation*}
      🔗
      🔗
    🔗
    🔗
    🔗

    Binary Operations.

    Our English word “algebra” comes from the Arabic word al-jabr, meaning “the reunion of broken parts”. It is not surprising, then, that we will consider ways of combining two elements of a set into one. To do this, we turn to a particular type of function known as a binary operation. Let \(X\) be a nonempty set.
    • A function \(\star: X\times X \to Y\) is called a binary operation on \(X\). That is, the function \(\star\) takes two numbers in the set \(X\text{,}\) and outputs another number, potentially in a different set \(Y\text{.}\) Given \(a,b\in X\text{,}\) we usually write \(a\star b\) in place of the typical function notation \(\star(a,b)\text{.}\)
      🔗
      🔗
    • If \(\star\) is a binary operation on \(X\) such that \(\star:X\times X \to X\text{,}\) then \(X\) is closed under \(\star\).
      🔗
      🔗
    🔗

    Example 1 Ordered pairs.

    Say \(X = \mathbb{Z}\text{.}\) Let \(\cdot\) be the binary operation multiplication. Then, with the function notation, we could write \(\cdot(2,3) = 6\text{,}\) though we usually write \(2\cdot 3=6\text{.}\)
    🔗
    Since, whenever \(x,y \in \mathbb{Z}\) we have \(x\cdot y \in \mathbb{Z}\text{,}\) we can say \(\cdot: X\times X \to X\text{.}\) Thus, \(\mathbb{Z}\) is closed under the operation \(\cdot\text{.}\)
    🔗
    However, \(\mathbb{Z}\) is not closed under the binary operation \(\div\) because, for example, \(\div(2,3)= 2\div 3 = \frac{2}{3}\not\in\mathbb{Z}\text{.}\)
    🔗
    🔗
    🔗

    Fields.

    A field is a set \(F\) together with two binary operations, called addition ( \(+\) ) and multiplication ( \(\cdot\) ), denoted as the triple \((F, +,\cdot)\text{,}\) such that all of the following axioms hold:
    🔗
    1. The set \(F\) is closed under addition and multiplication, meaning that for all \(x,y\in F\text{,}\)
      \begin{equation*} x+y \in F \text{ and } x\cdot y \in F\text{.} \end{equation*}
      🔗
      🔗
    2. Addition and multiplication are associative, meaning that for all \(x,y,z\in F\text{,}\)
      \begin{equation*} (x+y)+z = x+(y+z), \text{ and } (x\cdot y)\cdot z = x\cdot(y\cdot z)\text{.} \end{equation*}
      🔗
      🔗
    3. Addition and multiplication are commutative, that is, for all \(x,y\in F\text{,}\)
      \begin{equation*} x+y = y+x \text{ and } x \cdot y = y\cdot x\text{.} \end{equation*}
      🔗
      🔗
    4. The set \(F\) contains an additive identity. That is, there exists an element \(0_{F} \in F\) such that
      \begin{equation*} \text{ for all } a \in F, \text{ } a+0_{F} = a\text{.} \end{equation*}
      🔗
      🔗
    5. The set \(F\) contains a multiplicative identity. That is, there exists an element \(1_{F} \in F\) such that
      \begin{equation*} \text{for all } a\in F,\text{ } 1_{F} \cdot a = a\text{.} \end{equation*}
      🔗
      🔗
    6. Every element of \(F\) has an additive inverse in \(F\), meaning that for every \(x\in F\text{,}\)
      \begin{equation*} \text{there exists a } y\in F \text{ such that } x+y = 0_{F}\text{.} \end{equation*}
      🔗
      🔗
    7. Every nonzero (i.e., not \(0_{F}\)) element of \(F\) has a multiplicative inverse within \(F\), meaning that for every \(x\in F\text{,}\) there exists a \(y\in F\) such that
      \begin{equation*} x\cdot y =1_{F}\text{.} \end{equation*}
      🔗
      🔗
    8. Multiplication distributes over addition, meaning that, for all \(x,y,z \in F\text{,}\)
      \begin{equation*} x\cdot(y+z) = x\cdot y + x\cdot z\text{.} \end{equation*}
      🔗
      🔗

    Polynomials.

    A good deal of time is spent studying polynomials in algebra courses that are intended to be a preparation for the study of calculus. A polynomial in \(x\) over \(\mathbb{R}\) is an expression of the form
    \begin{equation*} a_{n} x^{n} + a_{n-1}x^{n-1}+\cdots + a_{2}x^{2} + a_{1} x^{1} + a_{0} x^{0}. \end{equation*}
    The set of all polynomials in \(x\) over \(\mathbb{R}\) is denoted \(\mathbb{R}[x]\text{.}\) We’ll use the addition and multiplication you likely learned in high school (in addition, you “add like terms”, in multiplication you need to use the distributive property).

    3.

    Consider \((\mathbb{R}, -,\div)\text{.}\) That is, the real numbers, but in the field axioms, replace addition with subtraction, and multiplication with division. Is \((\mathbb{R}, -,\div)\) a field?
    🔗

    Rectangle Math.

    This definition of multiplication is taken from James Tanton (who is math YouTube famous).
    🔗
    Here’s how it works: To compute the product of two numbers, say four times three, draw a four-by-three array of dots and count the number of (horizontal/vertical) rectangles one can draw with vertices on the grid. (Squares are also considered rectangles.)
    🔗
    🔗
    Here, there are six \(1\times 1\) rectangles, three \(1\times 2\) s, four \(2\times 1\) s, two \(2\times 2\) s, two \(3\times 1\) s, and one \(3\times 4\text{,}\) giving a total of eighteen rectangles. So,
    \begin{equation*} 4\times_{\square} 3 = 18. \end{equation*}
    Here the \(\times_{\square}\) is standing for “rectangle multiplication”.
    🔗

    Weekly Practice 1.

    1. A field of ordered pairs?

    Consider the set \(\mathbb{Z}\times \mathbb{Z}\) (the set of all ordered pairs of integers). For elements \((a,b), (c,d) \in \mathbb{Z} \times \mathbb{Z}\text{,}\) we define addition as \((a,b)+(c,d) = (a+c, b+d)\) and we define multiplication as \((a,b)\cdot(c,d) = (ac,bd)\text{.}\) Which of the field properties hold for \((\mathbb{Z}\times \mathbb{Z}, +, \cdot)\text{?}\) Does your answer change for \(\mathbb{R}\times \mathbb{R}\text{?}\)
    🔗
    🔗

    2. Playing with distribution.

    It is one of the axioms of the integers that multiplication distributes over addition. That is, for all integers \(a,b,\) and \(c\text{,}\) \(a\cdot (b+c) = a\cdot b + a\cdot c\text{.}\)
    🔗

    (a)

    What it would mean for addition to distribute over multiplication in the integers? Write a precise definition. (Like what’s written at the start of this question.)
    🔗
    🔗

    (b)

    In the integers does addition distribute over multiplication? Give a proof or a counterexample.
    🔗
    🔗

    (c)

    In the integers, does addition distribute over addition? Write a precise definition, and give a proof or a counterexample.

    3. Messing with zero.

    You’ve known for a while that for any integer \(a\text{,}\) \(0\cdot a = 0\text{.}\)
    🔗

    (a)

    How would you explain to an elementary schooler that \(0\cdot 2 = 0\text{?}\)
    🔗
    🔗

    (b)

    It turns out to be true in any field \(F\) that for any \(a\in F\text{,}\) \(0_{F} \cdot a = 0_{F}\text{,}\) where \(0_{F}\) is the additive identity. (Actually, this works in any ring, but you don’t know what a ring is yet!)
    🔗
    Prove that for any field \(F\) and any \(a\in F\) that \(0_{F} \cdot a = 0_{F}\) using only the field properties.
    🔗
    Hint 1.
    Consider \((0_{F} + 0_{F}) a\) in two different ways. See me if/when you get stuck!
    🔗
    🔗
    Hint 2.
    This may at first seem silly (even elementary schoolers sort of know this!), but actually, it’s not that obvious. To see why this is not obvious - try thinking a little more abstractly - why should the additive identity of a field, multiplied by anything, give back the additive identity? The only thing that we know about the additive identity is that when you add it to anything, it doesn’t change it. There’s no reason it should have any reasonable interaction with multiplication.
