    Isomorphism definition.

    What we want is for the addition and multiplication tables to “match up” (up to a reordering). Of course, writing this all down and redrawing addition and multiplication tables would be tedious, and impossible for infinite groups. So, consider that in our \(\mathbb{Z}_{2}\oplus\mathbb{Z}_{3}\) addition table we had:
    \begin{equation*} (1,2) + (0,1) = (1,0) \end{equation*}
    and we said
    \begin{equation*} (1,2)\to [5], \,\,\,(0,1)\to [4], \,\,\, \text{ and }\, \,\, (1,0)\to [3]. \end{equation*}
    So the header column of this entry gets replaced with \([5]\text{,}\) the header row with \([4]\) and the entry with \([3]\text{.}\) For this to match the \(\mathbb{Z}_{6}\) addition table, we need
    \begin{equation*} [5]+[4] = [3], \end{equation*}
    which it does! Calling our map or function \(\phi\) and writing \(\phi((1,2))= [5], \phi((0,1))= [4],\) and \(\phi((1,0))= [3]\text{,}\) what we need is
    \begin{equation*} \phi((1,2)) + \phi((0,1))=[5]+[4] =[3]= \phi((1,0))=\phi((1,2)+(0,1)) \end{equation*}
    We call this idea, that \(\phi(a)+\phi(b) = \phi(a+b)\text{,}\) preserving addition.
    🔗

    Definition 46.

    Let \(R\) and \(S\) be rings. An isomorphism is a bijective function \(\phi: R \to S\) such that for all \(x,y\in R\text{,}\)
    \begin{gather*} \phi(x+y)=\phi(x) + \phi(y) \text{ and }\\ \phi(xy) = \phi(x)\phi(y) \end{gather*}
    If there exists an isomorphism from \(R\) to \(S\text{,}\) then \(R\) is said to be isomorphic to \(S\text{,}\) denoted \(R \cong M\text{.}\)
    🔗
    🔗
    🔗

    Proving isomorphism.

    Theorem 47.

    Let \(\mathcal{M}= \left\{\begin{bmatrix}a &-b \\ b &a\end{bmatrix} : a,b\in\mathbb{R}\right\}\text{.}\) Then \(\mathcal{M}\) is a ring and \(\mathcal{M}\cong \mathbb{C}\text{.}\)

    Invariants.

    Definition 48.

    An invariant of ring isomorphism is a property \(P\) such that if \(R\) satisfies \(P\) and \(R\cong S\) then \(S\) satisfies \(P\text{.}\)
    🔗
    🔗
    Let’s prove that having a multiplicative identity is an invariant of rings. That is:
    🔗

    Theorem 49.

    If \(R\) and \(S\) are rings, if \(R\) has a multiplicative identity and \(R\cong S\text{,}\) then \(S\) has a multiplicative identity.

    2. A matrix isomorphism.

    Let \(M = \left\{ \begin{bmatrix}x &0\\ -x &0\end{bmatrix}: x\in\mathbb{R}\right\}\text{.}\) Let \(\phi: M \to \mathbb{R}\) be defined by
    \begin{equation*} \phi\left( \begin{bmatrix}x &0\\ -x &0\end{bmatrix} \right) = x. \end{equation*}
    This problem will show \(\phi\) is an isomorphism and thus \(M\) and \(\mathbb{R}\) are isomorphic.
    🔗

    (a)

    Show \(\phi\) is an injection by showing for \(A,B\in M\) if \(\phi(A) = \phi(B)\) then \(A = B\text{.}\) Then show \(\phi\) is a surjection by showing for an arbitrary \(a\in \mathbb{R}\) there exists \(A\in M\) such that \(\phi(A) = a\text{.}\)
    🔗
    🔗

    (b)

    Show \(\phi\) preserves addition by showing for all \(A,B \in M\text{,}\) \(\phi(A+B) = \phi(A) + \phi(B)\text{.}\)
    🔗
    🔗

    (c)

    Show \(\phi\) preserves multiplication by showing for all \(A,B\in M\text{,}\) \(\phi(A\cdot B) = \phi(A)\cdot \phi(B)\text{.}\)
    🔗
    🔗

    (d)

    The above problems show that \(\phi\) is an isomorphism and hence \(M\) and \(\mathbb{R}\) are isomorphic. Since being a field is an invariant and \(\mathbb{R}\) is a field, we can conclude \(M\) is a field. Thus, every nonzero element of \(M\) is a unit. What is the identity of \(M\text{?}\) Find the multiplicative inverse of \(A = \begin{bmatrix}a &0 \\ -a &0\end{bmatrix}\text{.}\)

    3. Homomorphisms: Kind of like isomorphisms, but not.

    Let \(R\) and \(S\) be rings. A function \(\phi: R\to S\) is a homomorphism of rings if \(\phi(a+b) =\phi(a)+\phi(b)\) and \(\phi(ab)=\phi(a)\phi(b)\) for all \(a,b\in \mathbb{R}\text{.}\) (Notice how this is very similar to the definition of isomorphism, but something important is missing -- which requirement of an isomorphism is not required here?)
    🔗

    (a)

    Define \(\phi: \mathbb{Z}\to \mathbb{Z}_{5}\) by \(\phi(k) = [k]_{5}\text{.}\) Show that \(\phi\) is a homomorphism.
    🔗
    🔗

    (b)

    The kernel of a homomorphism \(\phi\) is the set \(\text{Ker}(\phi) = \{ r\in R: \phi(r) = 0_{S}\}\text{.}\) Find \(\text{Ker}(\phi)\) for the \(\phi\) in part (a).
    🔗
    🔗

    (c)

    Prove the kernel you found in part b is an ideal of \(\mathbb{Z}\text{.}\) (It turns out the kernel of a ring homomorphism is always an ideal.)
