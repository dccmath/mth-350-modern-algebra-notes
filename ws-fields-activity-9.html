    Exercises Weekly Practice 1

    11.

    Consider the set \(\mathbb{Z}\times \mathbb{Z}\) (the set of all ordered pairs of integers). For \((a,b), (c,d)\text{,}\) we define addition as \((a,b)+(c,d) = (a+c, b+d)\) and we define multiplication as \((a,b)\cdot(c,d) = (ac,bd)\text{.}\) Which of the field properties hold for \((\mathbb{Z}\times \mathbb{Z}, +, \cdot)\text{?}\) Does your answer change for \(\mathbb{R}\times \mathbb{R}\text{?}\)
    🔗
    🔗

    12. Playing with distribution.

    It is one of the axioms of the integers that multiplication distributes over addition. That is, for all integers \(a,b,\) and \(c\text{,}\) \(a\cdot (b+c) = a\cdot b + a\cdot c\text{.}\)
    🔗

    (a)

    What it would mean for addition to distribute over multiplication in the integers? Write a precise definition. (Like what’s written at the start of this question.)
    🔗
    🔗

    (b)

    In the integers does addition distribute over multiplication? Give a proof or a counterexample.
    🔗
    🔗

    (c)

    In the integers, does addition distribute over addition? Write a precise definition, and give a proof or a counterexample.
    🔗
    🔗
    🔗

    13. Messing with zero.

    You’ve known for a while that for any integer \(a\text{,}\) \(0\cdot a = 0\text{.}\)

    Aside
    Zero is a weird concept. I have an entire book on zero in my office. From the back cover: “The Babylonians invented it, the Greeks banned it, the Hindus worshipped it, and the Church used it to fend off heretics.” Wow.
    🔗
    🔗

    (a)

    How would you explain to an elementary schooler that \(0\cdot 2 = 0\text{?}\)
    🔗
    🔗

    (b)

    It turns out to be true in any field \(F\)
     1 
    Actually any ring, but you don’t know what that is yet :)
    🔗
    that for any \(a\in F\text{,}\) \(0_{F} \cdot a = 0_{F}\text{,}\) where \(0_{F}\) is the additive identity.
     2 
    This may at first seem silly (even elementary schoolers sort of know this!), but actually, it’s not that obvious. To see why this is not obvious - try thinking a little more abstractly - why should the additive identity of a field, multiplied by anything, give back the additive identity? The only thing that we know about the additive identity is that when you add it to anything doesn’t change it. There’s no reason it should have any reasonable interaction with multiplication.
    🔗
    🔗
    Prove that for any field \(F\) and any \(a\in F\) that \(0_{F} \cdot a = 0_{F}\) using only the field properties.
     3 
    This is part of the motivation for the abstraction to fields. You’ve interacted with fields (like \(\mathbb{R}\)) for a long time. This abstraction allows us to explore the common features at the same time - it is inefficient to prove the same statement about every single field when we can prove it once and for all about fields in general.
    🔗
    🔗
    Hint.
    Consider \((0_{F} + 0_{F}) a\) in two different ways. See me if/when you get stuck!
